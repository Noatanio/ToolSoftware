This is my very first C++ project. Feel free to give feedback on GitHub.

It includes several tools such as a calculator, a to-do list, a file manager, and a stopwatch (which also works as a timer and clock).

You can compile the project using g++ with the following command:

g++ main.cpp file.cpp chrono.cpp calculator.cpp todolist.cpp -o ToolSoftware.exe
